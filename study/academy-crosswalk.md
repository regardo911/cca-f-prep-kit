## Anthropic Academy Course Crosswalk

Anthropic Academy is at `https://anthropic.skilljar.com/`. It hosts seventeen free courses. Some study guides cite "thirteen courses" as the catalog size; that figure is stale. Use seventeen.

The Claude Partner Network learning path consists of four courses (the ones partner-applicants name as load-bearing for partner-network admission):

| Academy course | Maps to book chapter |
|---|---|
| Introduction to agent skills | Chapter 7 (skills + slash commands + custom subagent definitions) |
| Building with the Claude API | Chapter 5 (Batch + structured outputs) and Chapter 8 (extractor) |
| Introduction to Model Context Protocol | Chapter 6 (MCP portability + 3-tool server) |
| Claude Code in Action | Chapter 7 (CLAUDE.md + hooks + plan mode) |

Additional Academy courses worth pairing with this book:

- **Introduction to subagents** → Chapter 4 (Hub-and-Spoke + AgentDefinition).
- **AI Capabilities and Limitations** + **AI Fluency: Framework & Foundations** → Chapter 10 (safety + trust hierarchy + responsible deployment).
- **Model Context Protocol: Advanced Topics** → Chapter 6 (deeper MCP patterns, beyond the 3-tool starter).

The four partner-path courses are required for any candidate on the Path 4 organizational-admission route from Chapter 2. They are recommended for every candidate regardless of access path; the Academy material is the canonical Anthropic-authored source for the SDK and platform behaviors the exam grades.
